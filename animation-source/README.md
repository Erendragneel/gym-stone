# Anime animation sources

The visual reference is the user's original **Oblique Exercise GIFs** collection and the supplied Glutes/Hips, Back, Shoulder, Biceps and Oblique ZIP files. The original Goblet Squat frames are preserved here as character and framing references.

Match the detailed anime athlete: black spiky hair, muscular anatomy with fine contours and cel shading, red sleeveless top, dark shorts, red sneakers, and a gray studio backdrop. The original chat specifies a 5.2-second instructional cycle, 0.8-second pauses at important positions, and a form cue beneath each exercise.

The 27 expanded/repaired exercises use six anime keyframes generated with the built-in image generation tool. Exact prompts and selected 3-by-2 sprite sheets are preserved here. `assemble-anime-loops.py` exports the selected poses as 768-by-620 GIFs and compact animated WebP files, with the reference timing and captions. These are illustrated instructional keyframe loops, not recorded footage or motion-captured coaching. The supplied original anime artwork is preserved for the other exercises.

Exercise IDs are unchanged so existing calendar plans and workout records keep their links. Generated sheets remain outside `dist`; only compact finished animations are served by the app.
