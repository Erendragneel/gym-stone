# Plate-loaded lat pulldown artwork

Built-in ImageGen generated one male sheet and one female sheet from the previous `expansion-v16/sheets/exp-plate-loaded-lat-pulldown.png` artwork as a reference for the character design and front view.

Use a 2×2 sprite sheet with one full seated athlete and one complete plate-loaded lat pulldown machine per cell. Keep the camera, character scale, seat, thigh pads, shoes, and machine base aligned. Draw the same anime athlete with dark hair, red top, black shorts, and red sneakers in every pose. From upper left to lower right, draw the overhead start, an early pull, a deeper pull, and the bottom with the handles near shoulder height. Keep each hand wrapped around its own lever handle and show the plates on the side. Use a white background and leave space around the entire subject.

The male midpoint sheet uses the same view and stationary parts. In its lower-right cell, place the hands at roughly forehead level, with elbows bending farther down and both grips and loaded levers still connected. Match the midpoint plate height to the adjacent poses so the plates keep rising throughout the pull.

The export uses five male poses and four female poses. Each variant reuses its poses in reverse for a controlled return and uses the same scale, frame margins, and cycle length.
